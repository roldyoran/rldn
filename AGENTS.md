# AGENTS.md

## Project Overview

Multi-feature workspace app (canvas, kanban, todos, notes). Monorepo: Turborepo + Bun workspaces. Stack: Astro 6, React 19, TailwindCSS 4, Starwind UI, Drizzle ORM, Better Auth, Turso (libSQL).

## Package Manager

**IMPORTANT**: This project uses **Bun** exclusively. Do NOT use npm, npx, yarn, or pnpm.

- Run scripts: `bun run <script>`
- Install packages: `bun add <package>`
- Run CLI tools: `bunx <tool>` (e.g., `bunx starwind@latest add button`)

## Commands

```bash
bun run dev:web          # Astro dev server (http://localhost:4321)
bun run typecheck        # Typecheck all packages
bun run typecheck:web    # Typecheck web only
bun run lint             # ESLint all
bun run format           # Format all
bun run db:generate      # Generate Drizzle migrations
bun run db:migrate       # Apply migrations to Turso
bun run db:push          # Push schema to Turso
bash scripts/db-setup.sh # Full DB setup (generate + migrate + push)
```

## Architecture

```
apps/web/src/
  pages/              → File-based routing (thin controllers)
  layouts/            → HTML shell (Layout.astro)
  features/           → Feature modules (self-contained)
    canvas/           → Excalidraw React island
    dashboard/        → Dashboard UI (Astro + Starwind)
  shared/             → Cross-feature code
    lib/              → api-auth.ts, auth.ts, auth-client.ts, db.ts
  styles/             → starwind.css, global.css (Excalidraw)
  components/starwind/ → Auto-generated by CLI (do not edit)
packages/db/          → Drizzle ORM + schema
packages/auth/        → Better Auth
```

**Dependency direction**: `pages/ → features/ → shared/`. Never reverse. Features never import from other features.

## Key Gotchas

### Env vars

- Two `.env` files: root + `apps/web/.env` — keep in sync
- `packages/db/src/index.ts` uses `process.env` (NOT `import.meta.env`)
- `apps/web/src/shared/lib/db.ts` uses `import.meta.env` (Vite-injected)

### Database

- Turso (libSQL). `@libsql/client` requires `libsql://` URLs — no local SQLite files.
- Schema: `documents` (universal base), `canvases`, `canvas_documents`, `images`, `kanban_data`, `todo_data`, `note_data` + auth tables.
- `documents` is the base entity for all features. Type discriminator: `'canvas' | 'kanban' | 'todo' | 'note'`.
- Auth tables: `timestamp_ms`. App tables: `timestamp` (unixepoch).
- Migration order: `db:generate` → `db:migrate` → `db:push`. Never `db:push` alone for new tables.

### Auth

- Better Auth, email+password only. Catch-all route: `/api/auth/[...all].ts`.
- Session check: `GET /api/auth/get-session` with `credentials: "include"`.
- All API routes require auth. Always use `credentials: "include"` client-side.

### Excalidraw

- Component: `apps/web/src/features/canvas/components/ExcalidrawEditor.tsx`
- `initialData` prop is mount-only. Do NOT pass data via re-renders.
- Theme: `theme="light"` (dark mode desaturates images).
- Grid color: monkey-patched via `CanvasRenderingContext2D.strokeStyle` interception. Verify hex values on Excalidraw updates.
- Auto-saves 1.2s after changes, on tab switch, and on page unload (64KB keepalive limit).

### Formatter

- Tabs for indentation, double quotes for strings.
- Run `bun run format` before committing.
